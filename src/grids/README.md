Pure Grids
==========

Pure Grids ship with build-in 5ths- and 24ths-based units styles. The unit style
rules are generated by [`lib/grids.js`](../../lib/grids.js), which is exported as
`generateGrids()` from the `purecss` npm package.

The tooling used by Pure to generate its built-in Grids can also be used to
create custom Grids that use any nth-unit base:

```js
const { generateGrids } = require('purecss');

console.log(generateGrids([12], {
    mediaQueries: { md: 'screen and (min-width: 48em)' },
}));
```
